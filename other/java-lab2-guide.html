I. Java Exceptions & Exception Handling

1. Checked Exceptions / Compile-time Exceptions

Question: Create a class called checkedExceptions. Check if a specific file exists. If not, handle FileNotFoundException. If it exists, read the file using a while loop. If it is not readable, handle IOException. 
import java.io.*;

public class CheckedExceptions {
    public static void main(String[] args) {
        File file = new File("D:\\myfile.txt");
        
        try {
            if (!file.exists()) {
                throw new FileNotFoundException("File not found at D:\\myfile.txt");
            }
            if (!file.canRead()) {
                throw new IOException("File exists but is not readable.");
            }
            
            BufferedReader br = new BufferedReader(new FileReader(file));
            String line;
            System.out.println("File Content:");
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
            br.close();
            
        } catch (FileNotFoundException e) {
            System.out.println("FileNotFoundException Handled: " + e.getMessage());
        } catch (IOException e) {
            System.out.println("IOException Handled: " + e.getMessage());
        }
    }
}
Explanation: Checked exceptions like FileNotFoundException and IOException must be explicitly caught or declared using throws. The try block monitors the file operations, and the respective catch blocks handle the errors if the file is missing or unreadable.

2. Unchecked Exceptions / Runtime Exceptions

Question: Create a class called uncheckedExceptions. Divide num1 (12) by num2 (keyboard input). Handle ArithmeticException (divide by zero) and InputMismatchException (invalid types like double or strings). 
import java.util.InputMismatchException;
import java.util.Scanner;

public class UncheckedExceptions {
    public static void main(String[] args) {
        int num1 = 12;
        Scanner sc = new Scanner(System.in);
        
        try {
            System.out.print("Enter num2: ");
            int num2 = sc.nextInt(); 
            
            int result = num1 / num2;
            System.out.println("The result after dividing 12 by " + num2 + " is " + result + ". No exception occurred.");
            
        } catch (ArithmeticException e) {
            System.out.println("java.lang.ArithmeticException: / by zero exception occurred. You cannot divide a number by zero.");
        } catch (InputMismatchException e) {
            System.out.println("java.util.InputMismatchException exception occurred. You cannot enter invalid input types. Please enter an integer value.");
        }
    }
}
Explanation: Runtime exceptions do not need to be declared in the method signature. If num2 is 0, the JVM throws an ArithmeticException. If the user types a string or decimal instead of an integer, Scanner.nextInt() throws an InputMismatchException.

3. Explicitly Throwing Exceptions

Explanation: The throw keyword is used to manually instantiate and trigger an exception based on custom business logic (e.g., failing eligibility criteria). The calling method must then catch it.

II. Threads & Thread Synchronization

1. Extending the Thread Class

Question: Create SubjectThread extending Thread. Use a loop to take 5 subjects as input, sleeping for 1 second each iteration. Check for InterruptedException. 
import java.util.Scanner;

class SubjectThread extends Thread {
    @Override
    public void run() {
        Scanner sc = new Scanner(System.in);
        for (int i = 1; i <= 5; i++) {
            System.out.print("Enter subject " + i + ": ");
            String subject = sc.nextLine();
            System.out.println("Subject entered: " + subject);
            
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                System.out.println("The thread is Interrupted");
                return;
            }
        }
        System.out.println("Thread successfully terminated");
    }
}

public class SubjectDemo {
    public static void main(String[] args) {
        SubjectThread st = new SubjectThread();
        st.start();
    }
}
Explanation: Extending Thread allows the class to behave as a thread. Thread.sleep(1000) pauses execution for 1000 milliseconds. st.start() creates a new call stack and executes the run() method.

3. Java Runnable Interface

Question: Create RunnableDemo implementing Runnable. Loop continuously while not interrupted. In main, start the thread, sleep 1000ms, then interrupt it. 
class RunnableDemo implements Runnable {
    @Override
    public void run() {
        while (!Thread.currentThread().isInterrupted()) {
            System.out.println("Thread is Running now");
        }
        System.out.println("Thread is terminated.");
    }
}

public class MainDemo {
    public static void main(String[] args) {
        Thread t1 = new Thread(new RunnableDemo());
        t1.start();
        
        try {
            Thread.sleep(1000);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        
        t1.interrupt(); // Interrupts and stops the thread
    }
}
Explanation: Implementing Runnable is often preferred because Java only allows single inheritance. The isInterrupted() flag safely controls the loop, and the main thread cleanly stops the worker thread by calling t1.interrupt().

4. Thread Synchronization

Question: Create a shared Count class with a synchronized printCount() method. Pass the same Count object to two different threads and execute them. 
class Count {
    public synchronized void printCount(int n) {
        System.out.println("Starting the Thread");
        try {
            for (int i = 0; i <= 5; i++) {
                System.out.println("Count Value = " + (n * i));
                Thread.sleep(100);
            }
        } catch (InterruptedException e) {
            System.out.println("Thread interrupted.");
        }
        System.out.println("Thread Terminated\n");
    }
}

class ThreadDemo1 extends Thread {
    Count c;
    public ThreadDemo1(Count c) { this.c = c; }
    @Override
    public void run() { c.printCount(100); }
}

class ThreadDemo2 extends Thread {
    Count c;
    public ThreadDemo2(Count c) { this.c = c; }
    @Override
    public void run() { c.printCount(10); }
}

public class DemoThreadSync {
    public static void main(String[] args) {
        Count sharedObj = new Count();
        ThreadDemo1 t1 = new ThreadDemo1(sharedObj);
        ThreadDemo2 t2 = new ThreadDemo2(sharedObj);
        
        t1.start();
        t2.start();
    }
}
Explanation: The synchronized keyword ensures that once a thread enters printCount(), it acquires a lock on the sharedObj. The second thread must wait until the first finishes before it can start executing the method, preventing mixed output.

2. Email Formatter (String Methods)

Question: Clean up an email address using trim() and toLowerCase(). Check if it contains "@". Extract the username and domain using indexOf() and substring(). 
import java.util.Scanner;

public class EmailFormatter {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter email address: ");
        String rawEmail = sc.nextLine();
        
        String cleanEmail = rawEmail.trim().toLowerCase();
        
        if (!cleanEmail.contains("@")) {
            System.out.println("Invalid email format.");
            return;
        }
        
        int atIndex = cleanEmail.indexOf("@");
        String username = cleanEmail.substring(0, atIndex);
        String domain = cleanEmail.substring(atIndex + 1);
        
        System.out.println("Username: " + username);
        System.out.println("Domain: " + domain);
    }
}
Explanation: trim() removes whitespace padding. substring(start, end) extracts characters from the start index up to (but not including) the end index. If only the start index is provided, it extracts to the end of the string.

4. StringBuilder (Palindrome Checker)

Question: Use StringBuilder to reverse a phrase and check for palindromes. Then demonstrate append(), insert(), and delete(). 
import java.util.Scanner;

public class PalindromeChecker {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a phrase: ");
        String text = sc.nextLine();
        
        String processedText = text.replace(" ", "").toLowerCase();
        StringBuilder sb = new StringBuilder(processedText);
        String reversedText = sb.reverse().toString();
        
        if (processedText.equals(reversedText)) {
            System.out.println("This is a palindrome.");
        } else {
            System.out.println("This is not a palindrome.");
        }
        
        sb.reverse(); // Face forward again
        
        sb.append(" - Verified");
        System.out.println("After Append: " + sb.toString() + " | Capacity: " + sb.capacity());
        
        sb.insert(0, "[CODE] ");
        System.out.println("After Insert: " + sb.toString() + " | Capacity: " + sb.capacity());
        
        sb.delete(sb.length() - 9, sb.length());
        System.out.println("After Delete: " + sb.toString() + " | Capacity: " + sb.capacity());
    }
}
Explanation: StringBuilder operates directly on the same object in memory, making modifications (like reversing or appending) much more memory-efficient than performing standard String concatenations inside loops.

Q2. Find specific file names by extension

Question: Create a java program to find a specific file name by extension (ex: python file, java file) from a specific folder. 
import java.io.File;

public class ExtensionFilter {
    public static void main(String[] args) {
        File dir = new File("D:\\Projects");
        String extension = ".java";
        
        if (dir.exists() && dir.isDirectory()) {
            // Using a lambda expression to filter file names
            File[] files = dir.listFiles((d, name) -> name.endsWith(extension));
            System.out.println("Files with " + extension + " extension:");
            if (files != null) {
                for (File f : files) {
                    System.out.println(f.getName());
                }
            }
        }
    }
}
Explanation: Uses listFiles() combined with a FilenameFilter (implemented here concisely with a lambda expression) to only return files ending with the specified extension.

Q4. Read and display file contents with validation

Question: Create a java program that reads a file and displays the contents on the screen. Handle whether the specified file exists and whether it is readable. 
import java.io.*;

public class FileReaderDemo {
    public static void main(String[] args) {
        File file = new File("D:\\myfile.txt");
        
        if (!file.exists()) {
            System.out.println("Error: File does not exist.");
            return;
        }
        
        if (!file.canRead()) {
            System.out.println("Error: File is not readable.");
            return;
        }
        
        try (BufferedReader br = new BufferedReader(new FileReader(file))) {
            String line;
            System.out.println("--- File Contents ---");
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.out.println("An I/O error occurred: " + e.getMessage());
        }
    }
}
Explanation: Uses canRead() to verify permissions before attempting to read. A try-with-resources block (the parentheses after try) automatically closes the BufferedReader after execution, preventing resource leaks.

Q5. Read text file into ArrayList

Question: Create a Java program that reads a text file, stores its contents in an ArrayList, and then displays the ArrayList's contents. 
import java.io.*;
import java.util.ArrayList;
import java.util.List;

public class ArrayListFileRead {
    public static void main(String[] args) {
        File file = new File("D:\\myfile.txt");
        List<String> list = new ArrayList<String>();
        
        if (file.exists() && file.canRead()) {
            try (BufferedReader br = new BufferedReader(new FileReader(file))) {
                String line;
                while ((line = br.readLine()) != null) {
                    list.add(line);
                }
            } catch (IOException e) {
                System.out.println("I/O Error: " + e.getMessage());
            }
        }
        
        System.out.println("Contents stored in ArrayList:");
        for (String str : list) {
            System.out.println(str);
        }
    }
}
Explanation: Iterates through the file using br.readLine(). Instead of printing immediately, each line is pushed into the list collection using list.add(). A subsequent enhanced for-loop is then used to iterate through and display the collection.
