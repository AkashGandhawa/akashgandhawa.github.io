2. Shell Scripting (Labs 3 & 4)

  • Variables: Do not put spaces on either side of the equal sign (e.g., number=10)[cite: 3]. System variables are uppercase (e.g., $HOME, $BASH)[cite: 3]. Define null variables as var1=""[cite: 3].
  • Quotes: Double Quotes " " remove meaning of characters except \ and $[cite: 3]. Single quotes ' ' remain completely unchanged[cite: 3]. Back quotes execute commands[cite: 3].
  • Input: read variable takes terminal input[cite: 3]. read -p "Prompt" var adds text[cite: 3]. read -a names extracts multiple items into an array[cite: 3].
  • Arithmetic: Use expr 10 \* 3 or $((10+5))[cite: 3]. Operators: +, -, /, *, %, ++, --, **[cite: 3, 4].
  • Test Conditions (test or [ ]):
    • Numeric: -eq (==), -ne (!=), -lt (<), -le (<=), -gt (>), -ge (>=)[cite: 4].
    • Strings: =, !=, -n (not null), -z (is null)[cite: 4].
    • Files: -s (non-empty), -f (normal file), -d (directory), -w (writable), -r (read-only), -x (executable)[cite: 4].
    • Logical: ! (NOT), -a (AND), -o (OR)[cite: 4].

3. AWK Programming (Lab 7)

  • Syntax: awk '/search pattern/ {Actions}' file_name[cite: 5]. Each statement in Actions is delimited by a semicolon[cite: 5].
  • Built-in Variables: NR (current line count), NF (number of fields in current record), FS (field separator), RS (record separator), OFS (output field separator), ORS (output record separator)[cite: 5]. $0 is the whole line, $1 is the first field[cite: 5].
  • Operators: Standard math (+ - * / %), conditionals (> >= < <= == !=), logic (&& ||), and regex match (~ matches, !~ no match)[cite: 5].
  • Blocks: BEGIN { ... } executes once at startup (initializes variables). END { ... } executes once at the end (prints totals)[cite: 5].
  • Functions: length() (returns string length), match() (returns first position matched by regex), index() (searches string for first occurrence of a substring)[cite: 5].

Lab 6: Nature / Flowers Exercise[cite: 6]

Note: The lab sheets provide AWK as the primary pattern scanning tool, though standard `grep` commands are also typically accepted for these operations. Both are provided.

1. Create the empty text file as nature.txt[cite: 6]. 
touch nature.txt
2. Using the above paragraph search for the word flowers and display the lines containing the word[cite: 6]. 
# Using grep:
grep "flowers" nature.txt

# Using AWK:
awk '/flowers/' nature.txt
3. Search for the word flowers while ignoring case sensitivity[cite: 6]. 
# Using grep:
grep -i "flowers" nature.txt

# Using AWK:
awk 'tolower($0) ~ /flowers/' nature.txt
4. Display the line numbers of the lines containing the word pleasant[cite: 6]. 
# Using grep:
grep -n "pleasant" nature.txt

# Using AWK:
awk '/pleasant/ {print NR, $0}' nature.txt
5. Count the number of lines containing the word Flowers[cite: 6]. 
# Using grep:
grep -c "Flowers" nature.txt

# Using AWK:
awk '/Flowers/ {count++} END {print count}' nature.txt
6. Display all lines that do not contain the word Flowers[cite: 6]. 
# Using grep:
grep -v "Flowers" nature.txt

# Using AWK:
awk '!/Flowers/' nature.txt
