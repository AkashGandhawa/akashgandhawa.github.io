I. Java Strings & Builders

Strings are immutable objects; once a value is assigned, that specific object in memory cannot be changed. Modifying a string actually creates a brand new String object.

Code Example: == vs .equals()

public class Main {
    public static void main(String[] args) {
        String a = "Sri Lanka"; 
        String b = "Sri Lanka";
        if (a == b) { System.out.println("Yes"); } else { System.out.println("No"); } 

        String c = new String("Sri Lanka"); 
        String d = new String("Sri Lanka");
        if (c == d) { System.out.println("Yes"); } else { System.out.println("No"); } 
        if (c.equals(d)) { System.out.println("Yes"); } else { System.out.println("No"); } 
    }
}
Output:
Yes
No
Yes
Explanation: The == operator checks whether the references point to the exact same memory location (which is true for literal strings a and b in the String Pool, but false for c and d which are forced onto the heap via new). The .equals() method strictly evaluates the actual character content, returning true for c and d.

Code Example: String Methods

String a = "Sri Lanka";
System.out.println(a.length()); // Output: 9
System.out.println(a.charAt(1)); // Output: r
System.out.println(a.toLowerCase()); // Output: sri lanka
System.out.println(a.concat(" Travel")); // Output: Sri Lanka Travel
System.out.println(a.toUpperCase()); // Output: SRI LANKA
System.out.println(a.equals("Sri Lanka")); // Output: true
System.out.println(a.equalsIgnoreCase("sRi Lanka")); // Output: true

String c = new String("Batch IT at");
System.out.println(c.substring(2)); // Output: tch IT at
System.out.println(c.substring(1, 4)); // Output: atc (end index is exclusive)
System.out.println(c.replace('a', 'B')); // Output: BBtch IT Bt
System.out.println(c.replaceFirst("a", "B")); // Output: BBtch IT at
System.out.println(c.replace("at", "B")); // Output: BBch IT B
System.out.println(c.replaceFirst("at", "B")); // Output: BBch IT at

II. Exception Handling

An exception is an indication of a problem that occurs during a program's execution. Use only classes that extend Throwable directly or indirectly for exception handling.

  • Checked Exceptions: Enforced by the compiler (the catch-or-declare rule). A method must either handle the exception OR specify the exception using throws. Examples: IOException, FileNotFoundException.
  • Unchecked Exceptions: All exceptions that are direct or indirect subclasses of RuntimeException. These usually happen due to the defects of your code and are not checked at compile time. Examples: ArithmeticException, ArrayIndexOutOfBoundsException.

Understanding the Stack Trace

When an exception occurs and is not handled, the program terminates and outputs a Stack Trace. The Stack Trace includes:

  • The Name of the exception.
  • The Method-call stack at the time the exception happens.
  • The Throw point (the initial point at which the exception occurs).

Code Example: Unhandled Exceptions

import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n1 = sc.nextInt(); // User enters 34
        int n2 = sc.nextInt(); // User enters 0
        divide(n1, n2);
    }
    public static void divide(int n1, int n2) {
        System.out.println(n1 / n2); 
    }
}
Output:
Exception in thread "main" java.lang.ArithmeticException: / by zero
at Main.divide(Main.java:17)
at Main.main(Main.java:13)

Code Example: Multiple Catch Blocks & Checked Exceptions

import java.io.*;
public class Main {
    public static void main(String[] args) {
        try {
            FileReader fileReader = new FileReader("C:\\myfile.txt");
            BufferedReader bufferedReader = new BufferedReader(fileReader);
            System.out.println(bufferedReader.readLine());
            bufferedReader.close();
        } catch (FileNotFoundException e) {
            System.out.println("File Not Found");
        } catch (IOException e) {
            System.out.println("IO Issue");
        } finally {
            System.out.println("Finally block executed");
        }
    }
}
Explanation: The try block encloses the critical code. If there are multiple catch blocks, only the first matching block is executed. You cannot put a catch subclass exception type after its superclass type (e.g., FileNotFoundException must be caught before IOException). The finally block avoids resource leaks and executes whether the exception is thrown from the try block or not.

Code Example: Custom Exceptions & The throw Statement

The programmer can throw exceptions explicitly using any class derived from the Throwable class.

class InvalidXValException extends Exception {
    String message;
    InvalidXValException() { 
        message = "Need an integer greater than 30"; 
    }
}

public class Main {
    public static void main(String[] args) {
        int x = 21;
        try {
            if (x < 31) { 
                throw new InvalidXValException(); 
            }
        } catch (InvalidXValException e) {
            System.out.println(e.message); 
        }
    }
}

Code Example: Propagating Uncaught Exceptions & Overriding

If an exception is not caught by the method, it is passed to the previous method in the call stack until reaching the main method.

When overriding methods with exceptions:

  • If the superclass method does not declare an exception, the subclass overridden method cannot declare a checked exception, but can declare unchecked exceptions.
  • If the superclass method declares an exception, the subclass overridden method can declare the same, subclass, or no exception.
class Dog {
    void show() throws Exception { 
        System.out.println("Dog Class"); 
    }
}
class GermanShepherd extends Dog {
    // ArithmeticException is a subclass of Exception, so this is valid.
    void show() throws ArithmeticException { 
        System.out.println("Dog Class"); 
    }
}

Self-Study Question

  • Is it possible to handle more than one type of exception? After SE7: Yes. Since Java 7, multi-catch blocks allow you to handle multiple exceptions in a single catch block using the | operator.

III. Threads

Multithreading utilizes multiple threads of control within a single program. A thread is a single sequential flow of control (a light-weight process) within a program. Each thread has its own call stack, but threads use/share the memory of the process.

Code Example: Thread Creation

Threads can be created by extending the java.lang.Thread class or implementing the Runnable interface. Every thread begins as an instance of the Thread class.

// Method 1: Extend Thread
class MyThread extends Thread {
    public void run() {
        for(int i=0; i<5; i++) { System.out.println("My Thread"); }
    }
}

// Method 2: Implement Runnable
class MyRunnable implements Runnable {
    public void run() {
        for(int i=0; i<5; i++) { System.out.println("Runnable Thread"); }
    }
}

public class ThreadTester {
    public static void main(String[] args) {
        MyThread myThread = new MyThread();
        myThread.start(); // Triggers the thread and calls run()
        
        MyRunnable myRunnable = new MyRunnable();
        Thread thread = new Thread(myRunnable);
        thread.start();
    }
}
Explanation: The start() method must be invoked to start a new thread (a new call stack). The Thread Life Cycle consists of New, Runnable, Running, and Dead (or Waiting/blocking) states. Once a thread is dead, it can never be brought back to life.

Code Example: sleep()

sleep() slows down the execution. When a thread sleeps, it goes to the Wait State, and needs to wake up to return to the Runnable State.

public class ThreadTester implements Runnable {
    public static void main(String[] args) throws InterruptedException {
        Thread thread1 = new Thread(new ThreadTester());
        thread1.start();
        Thread thread2 = new Thread(new ThreadTester());
        thread2.start();
    }
    public void run() {
        for (int i=0; i<5; i++) {
            System.out.println(Thread.currentThread().getName() + " " + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                System.out.println(e);
            }
        }
    }
}

Code Example: yield() and join()

class MyRunnable implements Runnable {
    public void run() {
        System.out.println(Thread.currentThread());
        Thread.yield(); // Stops currently executing thread to allow other threads to run
        System.out.println(Thread.currentThread());
    }
}

public class ThreadTester {
    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new Thread(new MyRunnable());
        t1.start();
        
        t1.join(); // One thread will "join onto the end" of another thread.
        
        System.out.println(t1.isAlive()); // Output: false
    }
}

Code Example: Synchronization & Inter-Thread Communication

The synchronized keyword ensures that only one thread can execute a block of code or method at a time on the same object, preventing data corruption. Methods like wait(), notify(), and notifyAll() are used to coordinate threads.

class SharedResource {
    private int count = 0;
    private boolean available = false;

    // 1. Synchronized Method (Prevents thread interference)
    public synchronized void increment() {
        count++;
    }

    // 2. Inter-Thread Communication (Wait & Notify)
    public synchronized void produce() throws InterruptedException {
        while (available) {
            wait(); // Pauses execution until resource is consumed
        }
        System.out.println("Produced new resource.");
        available = true;
        notify(); // Wakes up the waiting consumer thread
    }

    public synchronized void consume() throws InterruptedException {
        while (!available) {
            wait(); // Pauses execution until resource is produced
        }
        System.out.println("Consumed the resource.");
        available = false;
        notify(); // Wakes up the waiting producer thread
    }
}

Thread Priorities & Advanced Concepts

  • Thread Priorities: Threads are run with priority values [1-10]. Time-slicing schedulers allocate time for executing threads. A thread entering the Runnable state with the highest priority among the pool gets the chance to execute (equal priority is uncertain).
  • Deadlocks & Daemon Threads: Additional advanced thread management concepts discussed theoretically in Java Multithreading.

Self-Study Questions

  • What are the overloaded constructors in the Thread class? Constructors include passing string names to identify the thread and passing Runnable target instances.
  • What is the use of the keyword 'volatile'? It prevents a thread from caching variables locally, ensuring that any read/write directly accesses main memory so updates are visible to all concurrent threads.

IV. Input/Output (I/O) File Handling

Streams read and write information from and to external sources/destinations (like a file on a disk or a network connection). Incoming streams read data, while outgoing streams write data. The usual steps are to open the stream, use the stream, and close the stream.

Code Example: Appending and Writing Data

import java.io.*;
public class Main {
    public static void main(String[] args) throws IOException {
        // 'true' parameter avoids erasing an existing file
        FileWriter fileWriter = new FileWriter("src/test.txt", true);
        PrintWriter printWriter = new PrintWriter(fileWriter);
        printWriter.println("Java");
        printWriter.close();
        
        // Writing fresh data
        PrintWriter pw = new PrintWriter("src/test.txt");
        pw.println("Moratuwa");
        pw.println("Batch 22");
        pw.flush();
        pw.close();
    }
}

Code Example: Reading Data (Single Character vs Lines)

To read characters from a file, a connection is established: FileReader fileReader = new FileReader(fileName);. The public int read() throws IOException method reads a single character, and returns -1 if there are no more characters to read.

import java.io.*;
import java.util.Scanner;
public class Main {
    public static void main(String[] args) throws IOException {
        // Approach 1: BufferedReader (Buffered IO)
        FileReader fr = new FileReader("src/test.txt");
        BufferedReader br = new BufferedReader(fr);
        String line = br.readLine();
        while(line != null){
            System.out.println(line);
            line = br.readLine();
        }
        br.close();

        // Approach 2: Scanner
        File file = new File("src/test.txt");
        Scanner sc = new Scanner(file);
        while(sc.hasNext()) {
            System.out.println(sc.nextLine());
        }
        sc.close();
    }
}
